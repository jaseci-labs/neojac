# Porting Rust

`neojac port` translates a Rust crate into a Jac module that behaves as the crate does, or
refuses it ([port](../toolchain/port.md)). This page is the mapping: each Rust construct port
translates and the Jac it becomes. It is printed from the table the translation itself reads
(`neojac port --mapping rust`).

rustc reads the crate, as it does to compile it, once for each target neojac builds Rust for,
and port translates the typed tree rustc checks: macros expanded, every expression with its
type. Where the readings agree the Jac is written once; where they differ it is written as
[C's](port-c.md) is.

A crate's every file under `src/` is ported, each to a Jac file of its own, and the crate is
read with the features the project builds it with: its extension module's (`[extensions]`),
else its defaults.

| Rust | Jac |
|---|---|
| `i32`, `u8`, `i64`, `usize`, `f64`, `f32`, `bool` | `i32`, `u8`, `i64`, `u64` (by the target's width), `float`, `f32`, `bool` |
| `fn f(a: i32, b: f64) -> i32 { ... a }` | `def f(a: i32, b: float) -> i32 { ... return a; }`: a body's last expression is what it returns |
| `struct P { x: f64, n: i32 }`, `P { x: 1.5, n: 2 }`, `p.x` | `struct P { has x: float = 0.0, n: i32 = 0; }`, `P(x=1.5, n=2)`, `p.x` |
| `impl P { fn area(&self) -> f64 { } fn new(x: f64) -> P { } }`, `p.area()`, `P::new(1.0)` | `def area -> float;` and `static def new(x: float) -> P;` in the struct, each with its `impl P.area -> float { }`; `p.area()`, `P.new(1.0)` |
| `trait Measure { type Unit; const SCALE: i32; fn size(&self) -> i32; fn unit(&self) -> Self::Unit; }`, of no type parameter; `impl Measure for Item { type Unit = u32; const SCALE: i32 = 2; fn size(&self) -> i32 { } }` of a struct or an enum of the crate; `x.size()`, `T::SCALE` | An interface, `obj Measure { comptime Unit: type; comptime SCALE: i32; def size -> i32 abst; def unit -> Self.Unit abst; }`, a constant of an integer type (of that type), a `bool` or a `&str` a compile-time member; a conformance, `impl Item(Measure) { comptime Unit: type = u32; comptime SCALE: i32 = 2; def size -> i32 { } }`; `x.size()` (`Measure.size(x)` where the type has a method of that name of its own), `T.SCALE`. A trait's provided method is refused |
| `struct Duo<T> { a: T, b: T }`, `enum Either<L, R> { Left(L), Right(R) }`, `impl<T> Duo<T> { fn swapped(&self) -> Duo<T> { } }`, `Duo { a: 1, b: 2 }`; `fn sized<T: Measure>(x: T) -> i32`, of the crate's traits; `fn larger<T: Measure>(a: &T, b: &mut T)`, a reference to a value of a type parameter | `struct Duo[T] { has a: T, b: T; def swapped -> Duo[T]; }` with `impl Duo.swapped -> Duo[T] { }`, `enum Either[L, R] { Left(f0: L), Right(f0: R), }`, `Duo(a=1, b=2)`, its type found from its fields; `def sized[T: Measure](x: T) -> i32`; `def larger[T: Measure](a: &T, b: &mut T)`, Jac's borrows of the value |
| `struct Label<'a> { name: Cow<'a, str>, key: &'a str }`, `enum Tag<'a> { Bold(&'a str) }`, `trait Named<'a> { fn label(&'a self) -> Label<'a>; }`, `impl<'a> Label<'a> { }`, `impl<'a> Named<'a> for Item { }`: a lifetime parameter that marks only what port writes with no borrow | The same declarations with no lifetime: `struct Label { has name: str, key: str; }`, `enum Tag { Bold(f0: str), }`, `obj Named { def label -> Label abst; }`. A lifetime names nothing in Jac; one that marks a borrow of a place (a `&'a mut T`, a `&'a T` of a value held in place, a field that holds one) is refused |
| `Cow<'a, str>`, `Cow::Borrowed(s)`, `Cow::Owned(text)`, `"p".into()`, `&cow`, `cow.len()`; `Cow<'a, [u32]>`, `Cow::Owned(v)`, `parts.len()`; another crate's function's `Cow<str>` (`String::from_utf8_lossy(b)`) | `str`, `s`, `str(text)` of a `String`, `"p"`, `cow`, `u64(len(cow.encode()))`; `list[u32]`, the list of the items of the `Vec` or the slice a variable holds, `[v[u64(k)] for k in range(int(v.len()))]`, `u64(len(parts))`; `str(String.from_utf8_lossy(..))`, its text. Reading shares what it holds; a `match` on `Cow::Borrowed` and `Cow::Owned` is refused |
| `#[derive(Clone, Copy)]` | Nothing: a Jac struct is copied where it is assigned or passed |
| `const N: i32 = 5;`, `static LIMIT: i32 = 9;` | `comptime N: i32 = 5;`, `glob LIMIT: i32 = 9;` |
| `enum Color { Red, Green = 4 }` (no variant holds fields), `Color::Red`; `enum Shape { Square(i32), Rect { w: i32, h: i32 }, Dot }`, `Shape::Square(3)`, `Shape::Rect { w: 2, h: 1 }`, `Shape::Dot` | `enum Color { Red = 0, Green = 4, }`, `Color.Red`; a sum, `enum Shape { Square(f0: i32), Rect(w: i32, h: i32), Dot, }`, a tuple variant's fields named `f0`, `f1`, ... and given by position, a struct variant's by name: `Shape.Square(3)`, `Shape.Rect(w=2, h=1)`, `Shape.Dot` |
| `type Rank = u32;`, `type Parts<'a, N> = Cow<'a, [N]>;` | `type Rank = u32;`, `type Parts[N] = list[N];` |
| `use std::collections::HashSet;` | Nothing: rustc has resolved every path a `use` names |
| `match n { 0 => a, 1 \| 2 => b, k if k > 9 => c, _ => d }` over integers, bools and enums of the crate, as a statement or as a `let`'s value; `match s { Shape::Square(k) => a, Shape::Rect { w, h: 2 } => b, _ => c }` over an enum of the crate whose variants hold fields | `match n { case 0: ... case 1 \| 2: ... case k if k > 9: ... case _: ... }`; class patterns on the sum's members, by position for a tuple variant and by name for a struct variant: `case Shape.Square(k): ... case Shape.Rect(w=w, h=2): ... case _: ...` |
| `#[cfg(test)] mod tests { #[test] fn adds() { assert!(add(1, 2) == 3); } }` | `test "adds" { if not (add(1, 2) == 3) { raise AssertionError("assertion failed: add(1, 2) == 3"); } }`: the crate is read once more as a test; a helper function of the module is a function of the file |
| `let x = 1;`, `let mut x: i64 = 1;`, `let x = x + 1;` in the same block; `let (a, mut b) = t;` | `x: i32 = 1;`, `x: i64 = 1;`, `x: i32 = x + 1;`; `unpacked: tuple[u32, u64] = t; a: u32 = unpacked[0]; b: u64 = unpacked[1];` |
| `if c { } else if d { } else { }`; `let x = if c { a } else { b };` | `if c { } elif d { } else { }`; `x: T = a if c else b;` |
| `while c { }`, `loop { }`, `break`, `continue` | `while c { }`, `while True { }`, `break;`, `continue;` |
| `for i in a..b { }`, `for _ in 0..n { }`; `for x in v`, `v.iter()`, `v[a..b].iter()` and their `enumerate()`, over a `Vec`; `for b in text.as_bytes()`, over a `&[u8]` | `for i = a while i < b with i += 1 { }`; a walk by index, `for at = u64(0) while at < u64(v.len()) with at += 1 { x = v[at]; }`, a range checked first by `rust.within` as Rust checks it; over bytes, `given: bytes = text.encode();` and the walk, each `b = u8(given[at])` |
| `return v;`, `x = v;`, `x += v;` and the other compound assignments | The same |
| `a + b`, `a - b`, `a * b` of integers and of floats | `a + b`, `a - b`, `a * b`: an overflow is an error in Rust, and Jac raises OverflowError; `a.wrapping_add(b)`, `wrapping_sub`, `wrapping_mul` of integers are `a +% b`, `a -% b`, `a *% b` |
| `a / b`, `a % b` of signed integers | `(a // b + 1) if (a % b != 0 and (a < 0) != (b < 0)) else (a // b)`, and the like for `%`: Rust rounds toward zero and Jac toward negative infinity |
| `a / b` of floats | `a / b` where `b` is a literal other than 0; else `(a / b) if b != 0.0 else a * math.copysign(float("inf"), b)` |
| `a << k`, `a >> k`, `a & b`, `a \\| b`, `a ^ b`, `!a` of integers | `wrapping_shl(a, k)`, `a >> k`, `a & b`, `a \\| b`, `a ^ b`, `~a` |
| `a < b`, `<=`, `>`, `>=`, `==`, `!=`, `a && b`, `a \\|\\| b`, `!a`, `-a` | The same comparisons, `a and b`, `a or b`, `not a`, `-a` |
| `x as i64`, `x as f64` (a type that holds every value); `x as u8` | `i64(x)`, `float(x)`; `u8.wrap(x)`: it keeps the low bits |
| `f(a, b)` | `f(a, b)` |
| `\|x\| x + 1`, given to another crate's method that calls it before it returns | `lambda (x: i32) -> i32 { return x + 1; }` |
| `fn f(t: &[u32])`, `t[i]`, `t.len()`, `for &x in t`; `f(&v)`, `&v[a..b]`, `&v[a..]`, `&t[..b]` of a `Vec` or a slice of numbers; `&v[i]` of a `Vec` of another crate's values, `v[i].len()`; `v[i].1 = x` of a `Vec` of tuples | `def f(t: Slice[u32])`, `t[i]`, `t.len()`, a walk by index; `f(v.as_slice())`, `v.as_slice().sub(a, b)`, `.sub_from(a)`, `t.sub(u64(0), b)`: `rust.Slice[T]`, the native `&[T]`, which borrows what it is a slice of and panics where Rust panics; `v[i]`, the item the `Vec` lends, which borrows it; `v[i] = (v[i][0], x)`, `x` held first where it has an effect |
| `5`, `5u8`, `1.5`, `true`; a `char` (`'x'`), `a < b` and `a == b` of chars, `c.is_whitespace()`, `Option<char>` and its `is_some_and(\|c\| ..)` | `5` where its type is given by what takes it, else `i32(5)`, `u8(5)`; `1.5`, `True`; a `char` is a `str` of one code point (`"x"`), compared by code point as Rust compares chars, `rust.char_is_whitespace(c)` (Unicode's White_Space, as Rust's own table gives it: Python's `isspace` also counts U+001C to U+001F), `str \\| None`, `(lambda (held: str \\| None) -> bool { if held is None { return False; } return f(held); })(o)`, `o` evaluated once |
| `b"ab"` given as a `&[u8]` | `b"ab"` |
| `Vec<u32>`, `HashMap<Vec<u8>, u32, FxBuildHasher>`, `v.push(x)`, `Vec::with_capacity(4)`, `v[i]`, `v[i] = x`: another crate's types, the standard library's among them | `Vec[u32]`, `HashMap[Vec[u8], u32, FxBuildHasher]`, each imported by its Rust path (`import from std.vec { Vec }`), `v.push(x)`, `Vec[u32].with_capacity(4)`, `v[i]`, `v[i] = x`: Rust's own items, called natively ([Rust modules](rust-modules.md)) |
| A value whose drop is significant (`HashSet`, `Regex`): a `let`, a by-value parameter, a struct's field | An `own` binding, dropped where its scope ends as Rust drops it; a struct of the crate holding one is an `obj` with an `own` field |
| `&str`, a string literal, `s.len()`, `s.replace('&', "&amp;")`; `&[u8]`, `b"ab"`, `&piece[a..b]`, `&text[..i]` | `str` (its `len` the UTF-8 length), `replaced: String = String.new(); replaced.push_str(s.replace("&", "&amp;"));` before the statement; `bytes`; a range through `rust`'s `slice_bytes`, `slice_str` and their `_from` forms, which panic where Rust panics |

## What is refused

Anything not in the table is refused with E4001, and nothing is written for the file: among
them a type or a trait whose lifetime parameter marks a borrow of a place, generics but the table's, a trait's provided
method or one with type parameters, another crate's trait implemented, another crate's methods
generic over a closure or a trait object but in the chains the table names (`filter`,
`sum`, `for_each`, `fold`), a `for` over an iterator that borrows its source mutably
(`drain()`), a slice of other than numbers and bytes, a `?` that converts the error but into a `Box<dyn Error>`, a `Display` impl of more than one `write!`, a value
that borrows kept past a local, `char`, raw pointers and `unsafe`, and a call of another
crate whose types Jac does not hold or that the import of Rust leaves out (its result
borrows from other than its receiver and its str or bytes arguments, or it may keep a
borrow of what it is given).
So is a construct in the table whose Jac would mean something else (E4005):

- **A float converted to an integer.** Rust stops at the type's ends and Jac raises.
- **A division whose operands are more than names.** Port tests the operands, and would
  evaluate them twice.
- **A method named `__init__` or `__post_init__`**, the own names of a Jac object's constructor and post-initializer.
